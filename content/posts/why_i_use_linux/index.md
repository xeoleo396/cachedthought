# What is Linux

First things first, if you have been living under a rock or are not really into computers? then Linux also called "GNU/Linux". It is important to understand that Linux itself is not the operating system but rather it is the name of the kernel which is used alongside  GNU (GNU is not another unix) and other userspace components. Combine them and you get everything you need to make your DE(Desktop Environment which can be anyone you like Hyprland, KDE, Gnome, Xcfe and Many more)! It also has your package managers(think apt,pacman,zypper etc), init systems(OpenRC, Systemd, etc), drivers, applications and so on! What we typically use is called a Linux Distribution or distro, common example are Ubuntu, Arch, Debian, Fedora, openSUSE and the distro I am currently one Artix!

# Why Am I using Linux?

First of all I must confess that I have a Windows 11 machine too **(Oh the Horror!)**. But I must tell you that due to me playing certain games (***cough*** Genshin, Reverse 1999 ***cough cough***) I need a Windows machine. So yeah. Anyways now on the burning question why am I using Linux? and how did I start?

Well I started simply with ***drum roll please*** **EndeavourOS!**, not what your were expecting dear reader? Well how did even land on EndeavourOS(From now on will be writing as EOS ;) ). It happened due to one simple thing. My operating systems class in my University. My laptop at the time for some reason struggled to run Ubuntu in an VM so I thought why run it on well my second ssd? (I had two ssds in that laptop). So I looked up like everyone, whats the best gaming distro. From what I remember this was the 2022-2023 There was no CatchyOS and EOS was at the time considered to be good. So I installed was suprised that it took only few mins to install and be ready. I learned the basic linux commmands like cd, ls, find, grep, etc on there and deleted the OS after I was done with my OS class.

Fast Forward two years and its the December 2025, Now My Laptop had Windows 11 and it was running awful! I tell you dear reader I was not having a blast. It was hell developing my FYP Project, So the allure of Linux called me and the Fact I had gotten another laptop on which I can game and stuff made the transition easier! so I decided I will delete Win11 Forever and Downloaded my First real Distro..

**Ubunt- Fedora With Gnome**   

Now Fedora I didnt use as much as many would, I used it for a few months and I had also somehow gotten Hyprland working on it and customized but... At the time I had not idea how to manage the dependencies between Kaggle's (Used For Datasets and ML Training, very good) Tensorflow and my own machines tensorflow, so at the end of December I killed Fedora and went to....

**Pop!OS**

Pop!OS... In all honestly I didnt even know what it was all about so I installed it cause it had gnome and stuff. I further developed my FYP on this while learning more about Linux, It was all working good until.... ***Cosmic DE***. Now you are wondering what the hell is Cosmic. As taken from System76(creator of Pop!OS) website

> Foundational software for designing beautiful user experiences. Use it on your favorite distro!

COSMIC is a free and open-source desktop environment and Wayland compositor for Linux, developed by System76. It was originally a modified version of GNOME for Pop!OS but has since been rebuilt from scratch using the Rust programming language.

Now dear reader Cosmic DE is not bad but I installed it like a fool during its initial launch and ended up bricking my Pop!OS install so I had decided lets switch back to EOS teehee no issues teehee. My Luck that day was terrible... On that day the Arch AUR got DDoSed... So I had to look for another OS. So after much research I ended up on my longest-used OS

**OpenSUSE Tumbleweed**

I loved this OS! So fucking much not going to lie. This OS stuck with me from January 2026 to September 2026. I used KDE, it will as well as learning how the commands actually works while also learning about various stuff like pyenv(very important for python programming on Linux). I finished up my assignments on it, my fyp. Started working on my home server on it. Developed so many CLI Programs for personal use. Learned about how gaming on Linux works. Also got really into using more open source software! Also learned about the file system in greater detail, like btrfs(which i am still using since I find it is safer to recover from). But why did I change? Well It was having issue in causing random freezing during working and I couldnt really fix it. and also it was just systemd which was going against my morals. So after backing up the important stuff, I gave my favorite OS one last salute and switch to my latest and current OS.

 **Artix Linux**

Artix Linux is a distro based upon on Arch but it is systemd-free. My current setup is Hyprland (old fedora setup converted to the new .lua standard). I have being using it as of this post's date. Two weeks. But these two weeks have been smooth sailing for me. As I am still in the initial stages of using Artix, I dont have any opinions on it for the time being.

My typical work use for Linux involves:
- Programming using Codium and neovim.
- Editing Documents, Spreadsheets, and various other documents using OnlyOffice.
- Reading and Managing my book collection using Calibre.
- Syncing Stuff Between my Laptop and other devices using Syncthing.
- Managing my home server.
- Browsing the Web as well as watching youtube and my jellyfin stuff.
- Gaming (Minimum maybe Idle game or a very light steam like stardew valley)

Thats what I basically use linux for. I hope you had fun reading into my experiences with Linux and why I love it. Maybe I will shift from Hyprland+Noctalia to Cosmic again *;p*
